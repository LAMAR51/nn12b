# استمارة التقديم — الكلية الأمنية | العاصمة SA-1

صفحة ويب ثابتة (Static) لاستمارة التقديم على الكلية الأمنية داخل سيرفر الرول بلاي «العاصمة SA-1».

## المحتوى

- `index.html` — الصفحة كاملة (HTML + CSS + JavaScript وشعارات مدمجة بصيغة base64)، ملف واحد بدون أي اعتماديات خارجية عدا خطوط Google Fonts.
- `.nojekyll` — لتعطيل معالجة Jekyll على GitHub Pages ونشر الملفات كما هي.
- `.github/workflows/deploy-pages.yml` — نشر تلقائي على GitHub Pages عند كل تحديث.

## المزايا

- 15 سؤالًا مقاليًا تُبنى ديناميكيًا مع شريط تقدّم يتتبع الأسئلة المُجابة.
- حقول البيانات الأساسية: الاسم داخل السيرفر، معرّف الديسكورد، والعمر داخل الشخصية.
- زر **نسخ الإجابات** ينسخ الاستمارة منسّقة إلى الحافظة.
- زر **تحميل كملف نصي** يحفظ الإجابات في ملف `.txt`.
- زر **مسح الاستمارة** لتفريغ جميع الحقول.
- تصميم متجاوب بالكامل ويدعم الاتجاه من اليمين إلى اليسار (RTL).

## الخصوصية

الصفحة تعمل بالكامل داخل متصفح الزائر. لا يوجد أي خادم خلفي ولا أي طلبات شبكة لإرسال البيانات — النسخ والتحميل يتمّان يدويًا من قبل المستخدم.

## التشغيل محليًا

```bash
python3 -m http.server 8000
```

ثم افتح <http://localhost:8000> في المتصفح.

## النشر

النشر يتم تلقائيًا عبر GitHub Actions، لكن يجب تفعيل GitHub Pages مرة واحدة يدويًا لأن إنشاء موقع Pages صلاحية إدارية لا يملكها توكن الـ workflow.

1. افتح **Settings → Pages**.
2. تحت **Build and deployment** اختر **Source: GitHub Actions**.
3. من تبويب **Actions** أعد تشغيل آخر workflow عبر **Re-run jobs** (أو ادفع أي تعديل جديد).
